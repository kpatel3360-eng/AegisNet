# AI-Powered Network Traffic Prediction and Cyber Attack Monitoring Dashboard

## Project Objective
This project aims to build an end-to-end AI-powered system that combines network traffic forecasting, cyber-attack detection, anomaly detection, risk analysis, and an interactive monitoring dashboard.

## Major Planned Modules
1. **Traffic Forecasting:** Predict future network traffic using historical data.
2. **Cyber Attack Classification:** Detect known malicious network traffic.
3. **Anomaly Detection:** Unsupervised/semi-supervised approach to identify unusual network behavior.
4. **Monitoring Dashboard:** An interactive React-based frontend to visualize traffic and alerts.
5. **Backend API:** A FastAPI backend to serve model predictions and data.

## Planned Technology Stack
- **Data Science & ML:** Python 3.11+, Pandas, NumPy, Scikit-learn, Matplotlib, Jupyter, Joblib
- **Backend:** FastAPI, SQLite
- **Frontend:** React, Tailwind CSS, Recharts
